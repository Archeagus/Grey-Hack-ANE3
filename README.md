# ANE3 — Archeagus Network Exploitation Environment Version 3

ANE3 is an evolving GreyScript automation for the hacking simulation Grey Hack
and mission-management framework built inside the game.

MapScan maps.
LibScan researches.
MissionScan understands the work.
Heartbeat observes.
Mission Runner coordinates.
ExpScan executes.

## Episode 11 Release

The Episode 11 directory contains the exact record-ready builds
demonstrated in Grey Hack Part 11.

These builds were smoke-tested before recording.
